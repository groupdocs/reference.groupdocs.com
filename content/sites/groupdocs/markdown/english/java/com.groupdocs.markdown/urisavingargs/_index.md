Provides information and controls for customizing how a resource URI is written during document-to-Markdown conversion.


An instance of this class is created for each resource and can be used to override
the default URI or file name.


Call #setResourceFileUri(String).setResourceFileUri(String) to change the URI that appears in the Markdown output.
If no override is set, the library uses the default 
resourceFileUri
.

**Example:**

````

 // Inside a custom URI export callback
 args.setResourceFileUri("https://cdn.example.com/assets/" + args.getResourceFileName());
 
````
