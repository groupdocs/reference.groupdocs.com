Contains information about a resource URI being written during conversion. Passed to [IUriExportStrategy.updateResourceUri(UriExportContext)](../../com.groupdocs.markdown/iuriexportstrategy#updateResourceUri-UriExportContext-).


Read the default values from 
resourceFileName
 and 
resourceFileUri
,
then call #setResourceFileName(String).setResourceFileName(String) or #setResourceFileUri(String).setResourceFileUri(String)
to override them.
