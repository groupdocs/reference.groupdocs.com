# GroupDocs.Markdown — API Reference Source Files

This repository holds the Markdown source files used to generate the **GroupDocs.Markdown**
API reference, published at <https://reference.groupdocs.com/markdown/>.

## About GroupDocs.Markdown

[GroupDocs.Markdown](https://products.groupdocs.com/markdown/) is a developer API for document
processing: export PDF, Word, Excel, and other formats to clean Markdown. It is available for the following platforms, each with its own
API reference:

- **.NET** — <https://reference.groupdocs.com/markdown/net/>
- **Java** — <https://reference.groupdocs.com/markdown/java/>
- **Python via .NET** — <https://reference.groupdocs.com/markdown/python-net/>

## Repository purpose

The files in this repository are used to:

- Build and maintain the official **GroupDocs.Markdown** API reference.
- Keep the reference in sync with the latest product release.
- Provide a consistent structure for automated Hugo builds and publication.

Content is English-only and compiled into a static site with [Hugo](https://gohugo.io/).
