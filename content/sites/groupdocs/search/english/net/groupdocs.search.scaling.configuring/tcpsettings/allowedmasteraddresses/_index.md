## TcpSettings.AllowedMasterAddresses property

Gets or sets the addresses from which a slave node accepts the connection of the master node: IPv4 addresses or host names, which are resolved at each connection. A connection from another address is closed at once and logged. The master node does not use the setting. The default value is `null`: a slave node accepts a connection from any address.

```csharp
public string[] AllowedMasterAddresses { get; set; }
```

### Property Value

A copy of the addresses, or `null`.
