## TcpSettings.ResponseTimeout property

Gets or sets the time in milliseconds in which the master node waits for the answer of a node to a request. A request that is not answered in time fails: a call of the network throws [`SearchException`](../../../groupdocs.search.exceptions/searchexception), and an operation reports the document or the shard by the [`ErrorOccurred`](../../../groupdocs.search.scaling.events/nodeeventhub/erroroccurred) event. The default value is Infinite: the master node waits without a limit. In any case the requests of a node fail at once when its connection is broken or when it sends nothing for 15 seconds.

```csharp
public int ResponseTimeout { get; set; }
```

### Property Value

The response timeout in milliseconds, or Infinite.
