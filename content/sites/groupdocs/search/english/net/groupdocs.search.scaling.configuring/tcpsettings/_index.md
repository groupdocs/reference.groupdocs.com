| [NetworkKey](../../groupdocs.search.scaling.configuring/tcpsettings/networkkey) { get; set; } | Gets or sets the secret key of the search network. The nodes of a network with the key prove to each other that they know it when they connect, and sign every message: a computer without the key can neither give commands to a node nor answer for a node, and a changed, repeated or forged message breaks the connection. All the nodes of a network have the same key. The key is not a part of the configuration of the network and is not sent over the network; the messages themselves are not encrypted. The default value is `null`: the nodes have no key and carry out the commands of any computer that connects to them, and each node writes a warning to its log when it is created. |
