## AddRange(IEnumerable&lt;string&gt;) {#addrange}

Adds the specified collection of words to this instance of the [`StopWordDictionary`](../../stopworddictionary).

```csharp
public void AddRange(IEnumerable<string> words)
```

| Parameter | Type | Description |
| --- | --- | --- |
| words | IEnumerable`1 | The collection of words to add to the dictionary. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | Thrown when *words* is `null`. |
| ArgumentException | Thrown when a word contains an unpaired surrogate. |
| InvalidOperationException | The call changes the dictionary of an index that contains documents, is not in the Ready status or is disposed. |

### Remarks

A word is added without the white space around it and in the lower case; a word that is `null`, empty or consists of white space is left out. The words are checked before the dictionary is changed: a call that throws an exception changes nothing.
