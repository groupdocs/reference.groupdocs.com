## AddRange(IEnumerable&lt;string&gt;) {#addrange}

Adds the specified collection of words to this instance of the [`SpellingCorrector`](../../spellingcorrector).

```csharp
public void AddRange(IEnumerable<string> words)
```

| Parameter | Type | Description |
| --- | --- | --- |
| words | IEnumerable`1 | The collection of words to add to the dictionary. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | Thrown when *words* is `null`. |
| InvalidOperationException | The index of the dictionary is disposed. |

### Remarks

A word that is `null` or empty, has more than 80 characters, or contains the characters U+0000, U+0001, tab, carriage return or line feed is not added; the [`ErrorOccurred`](../../../groupdocs.search.events/eventhub/erroroccurred) event of the index reports the number of such words.
