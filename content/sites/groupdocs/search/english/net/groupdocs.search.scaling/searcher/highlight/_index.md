## Searcher.Highlight method

Highlights the found terms in the text of the found document using the specified highlighter.

```csharp
public void Highlight(NetworkFoundDocument document, Highlighter highlighter, 
    HighlightOptions options)
```

| Parameter | Type | Description |
| --- | --- | --- |
| document | NetworkFoundDocument | The found document. |
| highlighter | Highlighter | The search result highlighter. |
| options | HighlightOptions | The highlight options. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentException | The options have a custom extractor or a word splitter, which cannot be sent to the shard (see [`CustomExtractor`](../../../groupdocs.search.options/textoptions/customextractor) and [`WordSplitter`](../../../groupdocs.search.options/textoptions/wordsplitter)). |

### Remarks

A cancellation that [`Cancellation`](../../../groupdocs.search.options/textoptions/cancellation) requests ends the call at once, and the highlighter gets no text. A shard that has got the request completes the highlighting, and its result is ignored.
