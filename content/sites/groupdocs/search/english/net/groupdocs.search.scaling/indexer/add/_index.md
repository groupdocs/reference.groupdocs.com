## Add(IList&lt;Document&gt;, IList&lt;string&gt;, IndexingOptions) {#add}

Performs an indexing operation. Indexing only from stream and structure is supported.

```csharp
public void Add(IList<Document> documents, IList<string> passwords, IndexingOptions options)
```

| Parameter | Type | Description |
| --- | --- | --- |
| documents | IList`1 | The documents from stream or structure. |
| passwords | IList`1 | The document passwords. |
| options | IndexingOptions | The add options. |

### Remarks

A cancellation that [`Cancellation`](../../../groupdocs.search.options/indexingoptions/cancellation) requests completes the operation at once: no document is sent anymore, and [`ErrorOccurred`](../../../groupdocs.search.scaling.events/nodeeventhub/erroroccurred) names each document that is not indexed. A shard that has got a document before the cancellation may still index it: the error names such a document as one that may be indexed, and [`DocumentIndexed`](../../../groupdocs.search.scaling.events/nodeeventhub/documentindexed) occurs when the shard has indexed it.
