## IndexingReport.Errors property

Gets the list of errors.

```csharp
public string[] Errors { get; }
```

### Property Value

The list of errors.

### Remarks

The list contains the errors that the index has reported since its previous indexing report: the errors of the operation and the errors reported between the operations, such as the errors of the opening of the index. The errors of searches are not listed. A report lists at most 10000 errors: the last line of a longer list gives the number of the other errors, and every error is reported by the [`ErrorOccurred`](../../../groupdocs.search.events/eventhub/erroroccurred) event of the index.
