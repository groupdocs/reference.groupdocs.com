## FileIndexingEventArgs.WordSplitter property

Gets or sets the custom word splitter used to split text into words.

```csharp
public IWordSplitter WordSplitter { get; set; }
```

### Property Value

The custom word splitter used to split text into words. A `null` value means that the built-in word splitter will be used.

### Remarks

The words that the splitter gives get the character replacements of the index, if it uses them (see [`UseCharacterReplacements`](../../../groupdocs.search/indexsettings/usecharacterreplacements)).

A text that fails while it is read is split up to the failure, and the document is indexed with an error, as without the splitter.

An index that stores the texts of the documents (see [`TextStorageSettings`](../../../groupdocs.search/indexsettings/textstoragesettings)) stores the whole text of the document: the words that the splitter gives are looked for in the text one after another, and the text between them, for example the spaces, is stored as well. A word that the text does not have there, for example a word that the splitter has changed, is indexed at its position, but the stored text keeps the text of the document instead. An index of an earlier version stored only the words that the splitter gave: such a document gets its whole text when it is indexed again.

The highlighting of a document that was indexed with a splitter needs the same splitter, see [`WordSplitter`](../../../groupdocs.search.options/textoptions/wordsplitter).
