## ExtractionHost.OcrConnector property

Gets or sets the OCR connector that recognizes the text of the images of the documents that are extracted in this process.

```csharp
public IOcrConnector OcrConnector { get; set; }
```

### Property Value

The OCR connector, or `null`. The default value is `null`.

### Remarks

The OCR connector of the indexing options ([`OcrConnector`](../../../groupdocs.search.options/ocrindexingoptions/ocrconnector)) is an object of the process of the index and is not passed to the process of the extraction, so the text of the images of the documents that are extracted in a separate process is recognized by this connector, as the indexing options enable it ([`OcrIndexingOptions`](../../../groupdocs.search.options/ocrindexingoptions)). When the options enable the recognition and this connector is `null`, the images are not recognized, and the index reports it once per operation by the [`ErrorOccurred`](../../../groupdocs.search.events/eventhub/erroroccurred) event.
