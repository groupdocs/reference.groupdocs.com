## ExtractionHost.CustomExtractors property

Gets the custom extractor collection.

```csharp
public CustomExtractorCollection CustomExtractors { get; }
```

### Property Value

The custom extractor collection.

### Remarks

The full example of implementing a custom extractor is presented in the documentation for the [`IFieldExtractor`](../../../groupdocs.search.common/ifieldextractor) interface.

The documents that are extracted in a separate process (see [`ExtractInSeparateProcess`](../../../groupdocs.search.options/separateprocessoptions/extractinseparateprocess)) are extracted only by these custom extractors: the custom extractors of the index ([`CustomExtractors`](../../indexsettings/customextractors)) and of the [`FileIndexing`](../../../groupdocs.search.events/eventhub/fileindexing) event ([`CustomExtractor`](../../../groupdocs.search.events/fileindexingeventargs/customextractor)) are objects of the process of the index and are not passed to the process of the extraction. Add the same extractors to this collection before [`Run`](../run) is called.
