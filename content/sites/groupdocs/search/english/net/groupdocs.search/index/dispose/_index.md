## Index.Dispose method

Releases all resources used by the [`Index`](../../index).

```csharp
public void Dispose()
```

### Remarks

The operations of the index that run, the asynchronous ones as well, are cancelled, and the method waits until they end; the folder of the index is released then. A handler of an event that disposes the index does not wait: the folder is released when the operations of the index end.

The methods that index, search, change or save a disposed index throw ObjectDisposedException, and its dictionaries cannot be changed. The properties of the index and the information about its documents remain available.
