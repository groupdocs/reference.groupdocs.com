## Index.SaveTo method

Saves the in-memory index to disk. Also saves the regular index to another folder. Does not change the settings of this index.

```csharp
public void SaveTo(string indexFolder)
```

| Parameter | Type | Description |
| --- | --- | --- |
| indexFolder | String | The path to the index folder to save. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | The index folder is `null`. |
| InvalidOperationException | The index performs another operation, the folder is the folder of this index, or it contains an index that is not replaced: an index of another version or a damaged index. |
| IOException | Another [`Index`](../../index) object uses the folder, in this process or in another one, or an index is saved or updated into the folder at the moment. |
| InvalidDataException | A file of the index is missing, which is found before the folder is changed, or damaged. |
| ObjectDisposedException | The index is disposed. |

### Remarks

An index of the current version that the folder contains is replaced by the saved index.

An index that performs another operation is not saved. An index with the status Failed is saved in the state that it has worked with, without the change that has failed, and keeps its status; its changed settings are not saved.
