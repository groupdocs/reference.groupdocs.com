## AddToRepository(Index) {#addtorepository}

```csharp
public void AddToRepository(Index index)
```

| Parameter | Type | Description |
| --- | --- | --- |
| index | Index | The index to add. |

### Exceptions

| exception | condition |
| --- | --- |
| ArgumentNullException | The index is `null`. |

### Remarks

The repository does not dispose of the index: dispose of it when it is no longer needed, see [`Dispose`](../dispose).

### Examples

The example demonstrates how to add an index to the index repository.

```csharp

IndexRepository indexRepository = new IndexRepository();

indexRepository.AddToRepository(index);
```
