## IndexSettings.UseFastLoading property

Gets or sets a value indicating whether an index stored on disk keeps additional data that speeds up its loading. The default value is `true`.

```csharp
public bool UseFastLoading { get; set; }
```

### Property Value

A value indicating whether an index stored on disk keeps the data that speeds up its loading.

### Remarks

The data takes additional disk space. Setting the value to `false` reduces the disk space used by the index, and the index takes longer to load.

The value can be changed at any time, including after documents are added to the index. When the value is changed to `false`, the data is deleted as soon as the value is saved in the index; data that cannot be deleted at that moment, for example because another process uses it, is deleted the next time the index is opened. When the value is changed to `true`, the data is created the next time the index is opened in its folder or its indexed terms are changed, for example by indexing, merging or optimization.

A value changed while an index uses these settings is saved in the index at once or, if the index performs an operation at that moment, when the operation is finished. A new index uses the settings with which it is created; an existing index that is opened uses the settings saved in it, which [`IndexSettings`](../../index/indexsettings) returns.

An index in memory keeps no such data: the value applies to the index when it is saved to disk.
