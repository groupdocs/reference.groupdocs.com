## SearchResult.Warnings property

Gets the warnings describing the result.

```csharp
public string Warnings { get; }
```

### Property Value

The warnings describing the result.

### Remarks

The warnings are separated by line breaks. They tell, for example, that the query has a stop word, that a limit of the occurrences is reached, that a part of a case-sensitive query is searched in any letter case, and the errors of the search, which the [`ErrorOccurred`](../../../groupdocs.search.events/eventhub/erroroccurred) event of the index reports as well.
