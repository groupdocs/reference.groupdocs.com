### Exceptions

| --- | --- |
| InvalidDataException | The data is damaged. |
| InvalidOperationException | The data ends before the instance is read. |

### Remarks

The data must be the data of the [`Serialize`](../serialize) method and come from a trusted source: it is checked for consistency, not for its origin. A document info gives [`GetDocumentText`](../../../groupdocs.search/index/getdocumenttext) the path of the indexed document whose text is generated, so an application that gets document infos from its users must check that a user may read the document.
