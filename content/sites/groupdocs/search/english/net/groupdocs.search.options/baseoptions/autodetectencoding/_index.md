## BaseOptions.AutoDetectEncoding property

Gets or sets a value indicating whether to detect encoding automatically or not. The default value is `false`.

```csharp
public bool AutoDetectEncoding { get; set; }
```

### Property Value

A value indicating whether to detect encoding automatically or not.

### Remarks

The detected encoding is given to the [`FileIndexing`](../../../groupdocs.search.events/eventhub/fileindexing) event. The encoding of a document that is extracted in a separate process (see [`ExtractInSeparateProcess`](../../separateprocessoptions/extractinseparateprocess)) is detected in that process.
