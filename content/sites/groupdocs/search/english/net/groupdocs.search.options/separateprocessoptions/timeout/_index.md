## SeparateProcessOptions.Timeout property

Gets or sets the maximum time to wait for the result of data extraction in a separate process. The default value is 10 minutes. The separate process also has to connect to the index within this time after it is started: a process that does not connect in time is stopped, and the error is reported by the ErrorOccurred event of the index.

```csharp
public TimeSpan Timeout { get; set; }
```

### Property Value

The timeout for data extraction in a separate process.
