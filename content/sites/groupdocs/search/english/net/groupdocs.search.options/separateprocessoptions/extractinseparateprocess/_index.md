## SeparateProcessOptions.ExtractInSeparateProcess property

Gets or sets a value indicating whether a separate process is used to extract data from documents. The default value is `false`. When this option is enabled, data extraction is performed in a separate process in only one thread. The specified number of threads is ignored when extracting in a separate process.

```csharp
public bool ExtractInSeparateProcess { get; set; }
```

### Property Value

A value indicating whether a separate process is used to extract data from documents.

### Remarks

The separate process is the program of [`AssemblyPath`](../assemblypath), which runs an [`ExtractionHost`](../../../groupdocs.search/extractionhost): the host extracts the documents with its own custom extractors ([`CustomExtractors`](../../../groupdocs.search/extractionhost/customextractors)) and its own OCR connector ([`OcrConnector`](../../../groupdocs.search/extractionhost/ocrconnector)). The custom extractors of the index ([`CustomExtractors`](../../../groupdocs.search/indexsettings/customextractors)) and of the [`FileIndexing`](../../../groupdocs.search.events/eventhub/fileindexing) event ([`CustomExtractor`](../../../groupdocs.search.events/fileindexingeventargs/customextractor)) and the OCR connector of the options ([`OcrConnector`](../../ocrindexingoptions/ocrconnector)) are objects of the process of the index and are not used for the documents that are extracted in a separate process. The encoding of a document ([`AutoDetectEncoding`](../../baseoptions/autodetectencoding)) is detected in the separate process as well.
