## OcrIndexingOptions.OcrConnector property

Gets or sets an OCR connector that is used for OCR processing. The default value is `null`, which means no OCR is used.

```csharp
public IOcrConnector OcrConnector { get; set; }
```

### Property Value

An OCR connector that is used for OCR processing.

### Remarks

The documents that are extracted in a separate process (see [`ExtractInSeparateProcess`](../../separateprocessoptions/extractinseparateprocess)) are recognized by the OCR connector of that process, [`OcrConnector`](../../../groupdocs.search/extractionhost/ocrconnector): this connector is an object of the process of the index and is not passed to the process of the extraction.
