## SearchDocumentFilter.CreateFileExtension method

Creates a filter for skipping documents that are not in the specified list of possible extensions.

```csharp
public static ISearchDocumentFilter CreateFileExtension(params string[] extensions)
```

| Parameter | Type | Description |
| --- | --- | --- |
| extensions | String[] | The list of possible extensions. |

### Return Value

A search document filter by document extension.

### Remarks

An extension, with or without the leading dot, is compared with the end of the path of a document after a dot, ignoring the case of the letters: "doc" and ".doc" match "a.doc" and "a.DOC", but neither "mydoc" nor "a.xdoc"; an extension of several parts, such as "tar.gz", matches "a.tar.gz". An empty extension matches a path whose file name has no extension.
