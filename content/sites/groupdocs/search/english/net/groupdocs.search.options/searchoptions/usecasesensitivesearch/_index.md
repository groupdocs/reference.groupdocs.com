## SearchOptions.UseCaseSensitiveSearch property

Gets or sets the flag of case sensitive search. The default value is `false`.

```csharp
public bool UseCaseSensitiveSearch { get; set; }
```

### Property Value

The flag of case sensitive search.

### Remarks

A word pattern and a regular expression are matched with the words without regard to the letter case, so in a case-sensitive search the parts of a query with them find the words in any case, and [`Warnings`](../../../groupdocs.search.results/searchresult/warnings) tells it; the other parts of the query are case-sensitive. A word that such a part finds is given in the found terms in its form in lower case, in upper case or with the first letter in upper case, and a word written in another mix of the cases is given in lower case.
