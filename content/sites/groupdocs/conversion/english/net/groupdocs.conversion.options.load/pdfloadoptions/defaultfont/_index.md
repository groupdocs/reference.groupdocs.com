## PdfLoadOptions.DefaultFont property

Default font for Pdf document. The following font will be used if a font is missing.

```csharp
public string DefaultFont { get; set; }
```

### Remarks

The default font is used only when it is available: installed on the machine or found in one of the [`FontDirectories`](../../../groupdocs.conversion/convertersettings/fontdirectories). Otherwise the setting has no effect and the engine's own fallback font replaces the missing font.
