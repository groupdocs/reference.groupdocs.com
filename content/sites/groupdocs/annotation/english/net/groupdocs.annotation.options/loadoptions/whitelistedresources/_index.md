## LoadOptions.WhitelistedResources property

Resources that are loaded even when [`SkipExternalResources`](../skipexternalresources) is true. An entry is either a host name (matches that host and its subdomains, for example "example.com") or an absolute URI prefix (for example "https://cdn.example.com/images/").
