この名前空間は、ドキュメントの読み込み、注釈付け、保存時に追加オプションを指定するクラスを提供します。


## クラス

| クラス | 説明 |
| --- | --- |
| [LoadOptions](../com.groupdocs.annotation.options/loadoptions) | ドキュメントを開いて注釈を付ける際に、追加オプション（パスワードなど）を指定できます。 |

## 列挙型

| 列挙 | 説明 |
| --- | --- |
| [FileType](../com.groupdocs.annotation.options/filetype) | ファイルの情報（タイプ、拡張子など）です。 |
