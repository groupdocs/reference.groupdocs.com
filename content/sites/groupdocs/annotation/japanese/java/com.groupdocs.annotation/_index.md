この名前空間は、すべての一般的なドキュメント形式に対して文書に注釈を付けるクラスを提供します。

この名前空間の主なクラスは次のとおりです:

 *  [Annotator](../../com.groupdocs.annotation/annotator) is the entry point for annotating documents.
 *  [AnnotatorSettings](../../com.groupdocs.annotation/annotatorsettings) provides an easy way to customize caching, logging behaviour etc.
 *  [Document](../../com.groupdocs.annotation/document) provides details about a document.

--------------------

この名前空間のメインクラスは [Annotator](../../com.groupdocs.annotation/annotator) です。このクラスは文書に注釈を付けるメソッドを提供します。


## クラス

| クラス | 説明 |
| --- | --- |
| [Annotator](../com.groupdocs.annotation/annotator) | 文書の注釈プロセスを制御するメインクラスを表します。 |
| [AnnotatorSettings](../com.groupdocs.annotation/annotatorsettings) | [Annotator](../com.groupdocs.annotation/annotator) の動作をカスタマイズする設定を定義します。 |
| [Document](../com.groupdocs.annotation/document) | ドキュメントのプロパティを表します |
