Gets or sets external resources allowed to be loaded when [`SkipExternalResources`](../skipexternalresources) is true. The default value is an empty list.

### Remarks

An entry is either a host name or an absolute URI prefix:

* A host name (such as "images.example.com") allows any resource on that host and its subdomains.
* An absolute URI (such as "https://cdn.example.com/assets/") allows resources with the same scheme, host and port, whose path starts with the path of the entry at a segment boundary.
