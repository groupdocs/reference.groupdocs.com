## LoadSaveOptions.OoxmlCompliance property

Gets or sets the OOXML compliance level to use when saving Word documents to OOXML formats (DOCX, DOCM, DOTX, DOTM, etc.). The default value is null, which means the compliance level will be determined automatically: - If the original document was in Transitional format, it will be preserved - Otherwise, Strict compliance will be used

```csharp
public OoxmlCompliance? OoxmlCompliance { get; set; }
```

### Remarks

This property allows you to explicitly specify the OOXML compliance level when saving Word documents. When set to null (default), the system will automatically preserve the original document's compliance level if it was Transitional, otherwise it will use Strict compliance.

This property only applies when saving to OOXML formats (DOCX, DOCM, DOTX, DOTM, FlatOpc, etc.). It is ignored for other file formats.
