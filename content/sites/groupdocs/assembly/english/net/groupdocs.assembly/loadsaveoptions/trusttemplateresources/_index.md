## LoadSaveOptions.TrustTemplateResources property

Gets or sets a value indicating whether external resources referenced by the template document itself are trusted, i.e. loaded even when [`SkipExternalResources`](../skipexternalresources) is true. The default value is true.

```csharp
public bool TrustTemplateResources { get; set; }
```

### Remarks

A template document is usually written by the application's own authors, so resources it references are loaded by default. Resources whose references come from data are not trusted: data may be provided by other parties, so a URI it contains could make the application request internal addresses.

Set the value to false when templates come from untrusted sources, so that [`SkipExternalResources`](../skipexternalresources) applies to every external resource.
