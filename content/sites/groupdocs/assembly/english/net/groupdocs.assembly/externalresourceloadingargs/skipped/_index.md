## ExternalResourceLoadingArgs.Skipped property

Gets or sets a value indicating whether the resource is skipped: true to skip the resource (nothing is requested), false to load it.

```csharp
public bool Skipped { get; set; }
```

### Remarks

A skipped image is not inserted (for an `image` tag) or is replaced with a transparent image (for an image of a template document). A skipped document of a `doc` tag is not inserted.
