## PreviewOptions.Width property

Gets or sets the width of page preview images, in pixels. The default value is 0.

```csharp
public int Width { get; set; }
```

### Remarks

When both `Width` and [`Height`](../height) are greater than zero, page images are scaled to fit into the specified size keeping the aspect ratio of a page, and [`Resolution`](../resolution) is ignored. Otherwise, the size of an image is defined by the page size and [`Resolution`](../resolution).
