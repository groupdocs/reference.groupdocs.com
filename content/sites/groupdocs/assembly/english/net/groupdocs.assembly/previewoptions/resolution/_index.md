## PreviewOptions.Resolution property

Gets or sets the resolution of page preview images, in dots per inch. The default value is 96.

```csharp
public int Resolution { get; set; }
```

### Remarks

A page that is 8.5 inches wide is rendered 816 pixels wide at 96 dpi and 1700 pixels wide at 200 dpi. The value is ignored when both [`Width`](../width) and [`Height`](../height) are specified.
