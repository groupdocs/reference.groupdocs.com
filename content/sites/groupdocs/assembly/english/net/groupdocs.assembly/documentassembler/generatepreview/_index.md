## GeneratePreview(string, PreviewOptions) {#generatepreview_1}

Generates previews of pages of the document loaded from the specified file.

```csharp
public void GeneratePreview(string documentPath, PreviewOptions previewOptions)
```

| Parameter | Type | Description |
| --- | --- | --- |
| documentPath | String | The path to a document to preview. |
| previewOptions | PreviewOptions | Options for generating previews. |

### Remarks

A document of any file format supported by GroupDocs.Assembly can be previewed, for example, a template document or a document assembled by this class. Every page is rendered to an image written to a stream created by [`CreatePageStream`](../../previewoptions/createpagestream).

No external resources (such as remote images) are loaded while generating previews.
