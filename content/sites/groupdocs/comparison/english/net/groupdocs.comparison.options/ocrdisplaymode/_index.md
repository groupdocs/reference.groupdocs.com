## OcrDisplayMode enumeration

Controls how the result of comparing recognized text is laid out.

```csharp
public enum OcrDisplayMode
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| SideBySide | `0` | Default mode. Produces an image showing the source and the target side by side, each marked where it differs from the other, with the original layout of both preserved. |
| Text | `1` | Produces an image showing the recognized text of both documents as plain text, with deleted and inserted words highlighted. The layout of the original documents - fonts, tables, columns and images - is not reproduced. |
