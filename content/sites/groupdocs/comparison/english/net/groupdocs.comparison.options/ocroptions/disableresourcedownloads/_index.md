## OcrOptions.DisableResourceDownloads property

Gets or sets a value indicating whether to prevent downloading recognition models.

```csharp
public bool DisableResourceDownloads { get; set; }
```

### Property Value

`true` to fail when a required recognition model is not available locally; `false` to download it. Default is `false`.

### Remarks

Models are downloaded from the Aspose.OCR resource repository and stored in [`ResourcesPath`](../resourcespath). The setting applies to the entire process.
