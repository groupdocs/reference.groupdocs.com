## OcrOptions.Language property

Gets or sets the language of the text to recognize.

```csharp
public OcrLanguage Language { get; set; }
```

### Property Value

The language or script the documents are written in. Default is Latin.

### Remarks

Languages other than Latin require a recognition model that is not included in the package. See [`DisableResourceDownloads`](../disableresourcedownloads) and [`ResourcesPath`](../resourcespath).
