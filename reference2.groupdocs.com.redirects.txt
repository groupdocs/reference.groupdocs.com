# line, FIRST MATCH WINS (top to bottom). Applied by the Lambda@Edge function on the domain's
# CloudFront distribution, which reads this file from the repo root - so the PATH AND NAME OF
# THIS FILE ARE PART OF THE CONTRACT. Do not move or rename it. (It was moved to redirects/ in
# July 2026 and the rules stopped being applied; that is what this restores.)
#
# Provenance: maintained by infra from 2022-10 to 2025-03, then lost when `main`'s history was
# rewritten for the June-2026 modernization - 855972156b re-created the file with locale rules
# only, dropping all 59 legacy rules. Recovered from
#   git show origin/bunny.net-migration:reference.groupdocs.com.redirects.txt
# and repaired on the way in:
#   * 4 rules ended `$permanent;` (stray `$`) and so had never applied  -> `permanent;`
#   * 1 rule had a TAB between `rewrite` and its pattern                -> single space
#   * 1 watermark target had a doubled slash (`groupdocs.com//watermark`) -> single slash
# Two of the 59 recovered rules were dropped deliberately:
#   * `rewrite /tutorials/ https://tutorials.groupdocs.com/ permanent;` - unanchored and first,
#     so it shadowed the next rule and threw the path away. The anchored rule below covers it.
#   * `rewrite ^/viewer/net/groupdocs.viewer.options/webdocumentoptions(.*) ...` - obsolete;
#     `WebDocumentOptions` exists again (7 live pages) and the rule would redirect them away.
#
# ⚠️ These rules run on every request to the domain. Several of them collapse a trailing member
# segment (`/index/`, `/fields/`, `/properties/`, `/events/`) onto its parent, and some of those
# segments are real class names today - `GroupDocs.Search.Index` above all. Anything a rule would
# match but that is a LIVE page belongs in reference2.groupdocs.com.ignore_list.txt.
#
