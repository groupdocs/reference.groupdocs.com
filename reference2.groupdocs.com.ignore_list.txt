# Paths that must NEVER be redirected, one per line, even when a rule in
# reference2.groupdocs.com.redirects.txt matches them. Read by the same Lambda@Edge function.
#
# Why this file exists: several legacy rules collapse a trailing member segment (`/index/`,
# `/fields/`, `/properties/`, `/events/`) onto its parent, because those segments used to be
# URL scaffolding. Some of them are real class names today - `GroupDocs.Search.Index` is the
# Search product's flagship type - so without an exemption the rule that was written to rescue
# a dead URL redirects a LIVE page instead, and browsers cache that 301.
#
# The first two entries are the original list, restored verbatim from
#   git show origin/bunny.net-migration:reference.groupdocs.com.ignore_list.txt
# The rest were found by matching all 57 rules against the 30,256 live page URLs in
# content/sites/groupdocs (`url:` front matter, product prefix included): 23 pages collide.
# Both the trailing-slash and no-slash form of each is listed, following the original's example.
#
# ⚠️ This list is a SNAPSHOT. Every new API page whose last segment is `index`, `fields`,
# `properties`, `events` or `constructors` is a candidate. Re-derive it whenever the content
# tree changes materially, or a page will silently start redirecting to its parent.
